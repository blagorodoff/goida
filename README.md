# GOYDA — сайт цифровой студии

Статический сайт без сборщика и зависимостей npm. Основные страницы подключают общие HTML-компоненты, а галерея дизайна загружает изображения из `img/portfolio/design/`.

## Структура

- `index.html` — главная страница.
- `services/web.html` — услуга разработки сайтов.
- `services/branding.html` — айдентика и галерея графических работ.
- `games.html`, `games/` — игровые проекты.
- `components/` — общие шаблоны шапки, подвала и портфолио сайтов.
- `components.js` — подключение шаблонов и fallback для открытия страниц через `file://`.
- `style.css` — стили и адаптивные состояния.
- `script.js`, `design-gallery.js`, `contact-form.js`, `site-calculator.js` — интерактивность страниц.
- `img/works/` — фоновые обложки и скриншоты проектов сайтов.
- `img/portfolio/design/digital/` — digital-дизайн, иллюстрации и единая композиция из трёх рекламных баннеров.
- `img/portfolio/featured/` — облегчённые превью избранных работ для главной страницы; полные изображения остаются в соответствующих категориях портфолио.
- `img/portfolio/design/identity/` — фирменные стили и логотипы.
- `img/portfolio/design/print/` — полиграфия и книжное оформление.
- `img/portfolio/design/game-art/` — персонажи и окружение для игр.
- `img/portfolio/design/type/` — шрифтовой дизайн.
- `img/icons/`, `img/what-we-do/`, `img/why-goyda/` — интерфейсные и сервисные изображения.
- `video/` — фоновые и игровые ролики.
- `fonts/` — локальный display-шрифт.

## Локальный запуск

Из корневой папки проекта запустите:

```bash
python3 -m http.server 8080
```

Откройте `http://localhost:8080`. Общие шаблоны загружаются через `fetch`, поэтому для обычной разработки удобнее использовать локальный сервер, а не открывать HTML двойным щелчком.

## Изменение общих блоков

Редактируйте `components/header.html`, `components/footer.html` или `components/site-portfolio.html`. После изменения шаблонов обновите встроенные копии для режима `file://`:

```bash
python3 sync-component-fallbacks.py
```

## Добавление работы в галерею

Поместите изображение WebP в папку соответствующей категории внутри `img/portfolio/design/`. В `services/branding.html` скопируйте карточку `.design-pin`, обновите путь в `src` и `href`, категорию `data-gallery-category`, `alt` и подпись. Поддерживаемые категории: `identity`, `print`, `digital`, `game-art`, `type`. Счётчики фильтров обновляются автоматически.

Фоновые обложки портфолио сайтов находятся в `img/works/` и подключаются в `style.css`. Макеты экрана и мобильной версии каждого проекта находятся в том же каталоге.
