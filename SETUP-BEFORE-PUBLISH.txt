ГОЙДА — что настроить перед публикацией

1. Яндекс Метрика
   В components.js найдите строку:
   const METRIKA_COUNTER_ID = 0;
   Замените 0 на реальный номер счётчика из кабинета Яндекс Метрики. Пока номер равен 0, код Метрики не загружается. Счётчик запускается только если посетитель выбрал «Разрешить аналитику» в cookie-уведомлении.
   Для заново проверки баннера очистите localStorage/cookie с ключом goida_cookie_consent_v2.

2. Общие шаблоны
   Редактируйте components/header.html, components/footer.html и components/site-portfolio.html. После правок запустите:
   python sync-component-fallbacks.py
   Это обновит встроенные офлайн-копии для работы при открытии страниц двойным щелчком через file://.

3. Портфолио сайтов
   Структура изображений и рекомендации по обновлению портфолио описаны в README.md. Слайды портфолио общие для главной и страницы услуги «Сайты».

4. Контакты
   Номер +79898022026 задаётся в contact-form.js. Ссылки на Telegram и ВКонтакте находятся в index.html.

5. Важно для запуска аналитики
   Перед включением счётчика проверьте применимые обязанности оператора персональных данных, необходимость уведомления Роскомнадзора и требования к опубликованной информации о обработке данных. Короткое cookie-уведомление само по себе может не заменять обязательные документы.
